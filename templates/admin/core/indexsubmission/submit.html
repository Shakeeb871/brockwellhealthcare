Google Indexing API setup (one time, ~10 min) — this is the part that gets Google crawling in minutes:
  1. Google Cloud console → create a project.
  2. APIs & Services → Library → search Indexing API → Enable.
  3. APIs & Services → Credentials → Create credentials → Service account. Open it → Keys → Add key → JSON → download.
  4. Search Console → Settings → Users and permissions → Add user → paste the service account's client_email → permission Owner. (Without Owner, Google returns "Permission denied".)
  5. Upload the JSON to the server (outside public_html) and set in .env:
    GOOGLE_INDEXING_CREDENTIALS=/home/USER/google-indexing.json
    then redeploy.

Straight answer on speed: these APIs make Google crawl a URL within minutes — that part is real and it is exactly what paid "instant indexer" services do under the hood. Whether Google then keeps the page in its index is still Google's call; no tool or service can override that. For a new domain, also add the sitemap in Search Console and use URL Inspection → Request indexing on your most important pages, and get a few real external links (Google Business Profile, LinkedIn, directories) — that trust signal is what moves a new site fastest.
